================================================================================
MedCall AI - Product Overview
================================================================================

WHAT IT IS
----------
MedCall AI is a multi-project CRM and AI phone-calling platform for
pharmaceutical market research in Egypt. It calls physicians and pharmacists,
speaks Egyptian Arabic, follows drug research scripts, records and transcribes
calls, scores outcomes, and turns approved answers into structured data.

The dashboard is English-first, with Arabic support where needed. The phone AI
speaks Egyptian Arabic.

CORE CALL FLOW
--------------
1. A manager or campaign selects a project, script, and doctor call list.
2. Twilio calls the contact and plays the project's consent line.
3. Azure TTS speaks the greeting and research questions in Egyptian Arabic.
4. The contact's answers are recorded, transcribed, and processed by the AI.
5. The conversation can continue, end, or escalate to a human agent.
6. The call is scored, logged, transcribed, and optionally recorded in full.
7. Results update project progress, Excel data, analytics, and data-entry drafts.

MAIN FEATURES
-------------

1. Single and Mass Calling
   - Manual quick calls from the Call Center.
   - Campaigns for batches of contacts.
   - Bull/Redis queue with configurable concurrency.
   - Live call and campaign progress through Socket.io.
   - Pause/resume campaign controls.

2. Scripts and Lead Scoring
   - Scripts stored per drug/project.
   - Typed questions: open, yes/no, scale, and multiple choice.
  - Weighted answers produce a 0-100 lead score and cold/warm labels.

3. Contacts and Excel Data
   - Contacts page is the doctor call list.
   - Manual contact creation and editing.
   - Validate contact data with human review for changes.
   - Integrate a valid-doctors Excel sheet from the Data page.
   - Match doctors without creating duplicates.
   - Data-entry links may arrive later and appear in Data Entry Review.
   - Excel changes are validated, tracked as pending, and never silently
     overwrite existing doctor data.

4. AI Data Verification and Doctor Discovery
   - Check existing doctor information against public online sources.
   - Return proposed changes, confidence, evidence, and source URLs.
   - Find additional doctors by specialty, city, area, and need count.
   - Managers approve corrections and new candidates before they are added or
     called. AI never auto-calls discovered doctors.

5. Compliance and Recording
   - Consent is requested before the research call.
   - Consent verdict and exact answer are stored as evidence.
   - A denied-consent contact is not called again for recording.
   - Optional dual-channel full-call recording through Twilio.
   - Recordings, consent evidence, and transcripts can be archived to Google
     Drive with retryable background uploads.

6. Data Entry and Chrome Extension
   - AI extracts structured fields from completed-call transcripts.
   - Human reviewers compare fields with the transcript and approve/reject.
   - Approved payloads are validated against the project's form schema.
   - The MedCall Filler extension opens the doctor's unique data-entry link and
     fills the external website using project field mappings.
   - The representative always reviews and submits the external form manually.

7. Projects, Teams, Targets, and Insights
   - A registering user becomes a manager.
   - Managers create projects, add members, attach data, and set call/form
     targets.
   - Members work only on projects they are assigned to.
   - Progress is shown by project and by team member.
   - Gemini generates anonymized market insights with findings, segments,
     recommendations, risks, and data-quality caveats.

8. Project Configuration
   - Each project can have its own script and questions.
   - Each project can define its own form schema and validation rules.
   - Each project can define its own consent text and requirement toggle.
   - Each project can define a common data-entry website and field mapping.
   - Individual doctors can have unique data-entry URLs.
   - Missing settings fall back to global defaults.

9. Calendar and Requested Callbacks
   - If a doctor asks for another time, an agent adds a callback to Calendar.
   - The callback stores date, time, timezone, project, notes, and status.
   - The scheduler calls the doctor at the requested local time.
   - Callbacks can be cancelled or rescheduled and link to the final CallLog.

CURRENT NAVIGATION
------------------
- Calling -> Quick calls, Campaigns
- Operations -> Agent Console, Calendar
- Data -> Contacts, Calls, Review, Scripts, Excel sheets
- Reports -> Analytics, Market Insights
- Projects -> Projects and Project Settings
- Settings -> Integrations and Account

TECHNOLOGY
----------
- Frontend: React 18, Vite, React Router, Recharts, Axios, Socket.io client
- Backend: Node.js, Express, MongoDB, Mongoose, JWT authentication
- Queues: Bull and Redis for campaigns, callbacks, and Drive uploads
- Telephony: Twilio outbound calls, recordings, webhooks, and conferences
- Voice: Azure Speech TTS with Egyptian Arabic voices
- AI: Gemini for conversation support, extraction, verification, discovery, and
  market insights
- Speech processing: ASR service for call recordings and transcripts
- Files/data: ExcelJS, Multer, local Excel files, optional Google Sheets links
- Archive: Google Drive service-account integration
- Browser integration: Chrome Manifest V3 extension
- Deployment: Vercel frontend configuration with a backend service and API
  rewrites

ROLES
-----
- Manager: projects, members, scripts, contacts, Excel, campaigns, AI tools,
  insights, settings, and progress.
- Member: assigned project work, calls, reviews, contacts, and personal progress.

KEY SAFEGUARDS
--------------
- Human approval is required for Excel changes, AI corrections, new doctor
  candidates, extracted drafts, and external form submission.
- Search results include sources and confidence; AI does not silently change
  records or call newly discovered doctors.
- Consent denial prevents future recorded calls for that contact.
- Project and manager ownership controls data visibility.
- Schema snapshots protect historical drafts when project forms change.
- Queue, AI, Drive, Excel, and TTS failures should degrade gracefully and not
  crash the core call pipeline.

LOCAL DEVELOPMENT
-----------------
- Frontend: http://localhost:5173
- Backend: http://localhost:5000
- Install: `npm run install-all`
- Start: `npm run dev`
- Seed sample script and contacts: `npm run seed`
- Campaigns and callback scheduling require Redis.
- Twilio webhooks require a public development URL such as ngrok.
